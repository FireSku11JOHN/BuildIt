# 🟩 BuildIt – Tutoriais de Construções no Minecraft  

O *BuildIt* é um site criado para reunir *tutoriais de construções no Minecraft*.  
O projeto foi desenvolvido com o objetivo de praticar *HTML, CSS e JavaScript*, ao mesmo tempo em que compartilha ideias criativas para o jogo.  

---

## 🚀 Funcionalidades  

- ✅ Página inicial com destaque para os tutoriais  
- ✅ Cards de tutoriais com título, imagem, descrição e link para o vídeo  
- ✅ Organização por categorias (ex: casas, fazendas, estruturas modernas, etc.)  
- ✅ Navegação intuitiva entre páginas
  
*Novas funcionalidades estão sendo desenvolvidas*

---

## 🎯 Objetivo do projeto

O objetivo do BuildIt é ser um guia prático de construções no Minecraft, ao mesmo tempo que serve como base de aprendizado em desenvolvimento web:

- Criar um site temático e organizado

- Melhorar habilidades em front-end

- Praticar boas práticas em HTML, CSS e JavaScript

- Compartilhar tutoriais de maneira criativa e acessível

## 🛠 Tecnologias utilizadas  

- *HTML5* → Estrutura das páginas  
- *CSS3* → Estilização e responsividade  
- *JavaScript (ES6+)* → Interatividade e organização dos dados  
- *Git/GitHub* → Controle de versão
